Beginner Algorithms & Interview Preparation

A structured collection of core algorithmic problems and data structure exercises designed for beginners preparing for software engineering technical interviews, built with Python.

Overview
Mastering fundamentals like arrays, strings, and basic data structures is essential for passing technical screens. This repository focuses on writing clean, tested code to build strong problem-solving habits from the ground up.

Project Structure

Arrays/: Core implementations of array and string manipulation algorithms.

Tests/: Unit test suites using Python's built-in unittest framework to verify correctness.

Running the Tests
Execute the following command from the root directory of your project to run the array uniqueness test suite:

---
python -m unittest Tests/Arrays/StringElementsAreUniqueTests.py
python -m unittest Tests/Arrays/TwoArraySearchTargetTests.py
python -m unittest Tests/Arrays/GroupAnagramsTests.py
---
